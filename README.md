# Codex Usage Sentinel

Программа для Windows: раз в минуту проверяет оставшиеся лимиты Codex и отправляет личные уведомления в Telegram. Работает в трее. Ночная тема; активные функции зелёные с галочкой и полным текущим статусом. Собственный бот работает напрямую; общий бот требует отдельного сервиса.

**[Скачать один готовый EXE](https://github.com/antonstrobe/codex-usage-sentinel/releases/latest/download/CodexUsageSentinel.exe)** · [Все файлы релиза](https://github.com/antonstrobe/codex-usage-sentinel/releases/latest)

Опубликованный EXE — **Build 1.1.0**. В исходниках — **Build 1.2.0** с подключением общего бота через Start. Новый EXE пока не опубликован; сервис не установлен. Для обычной работы готовой версии нужен только `CodexUsageSentinel.exe`.

**Предупреждение о текущей версии:** при работе локальной сборки Defender обнаружил `Behavior:Win32/DefenseEvasion.A!ml`. Причина не установлена; до её выяснения установку EXE не рекомендуем. Проверки CI не исключают поведенческое обнаружение. Не отключайте защиту для запуска.

[Настройка второго пользователя](docs/SECOND_COMPUTER.md) · [Размещение общего бота](docs/SHARED_BOT.md). В исходниках реализованы ссылка Start на 10 минут, отдельные ключи компьютеров, привязка только своего чата и команда `/stop`. Токен общего бота клиентам не выдаётся. Проверки выполнены с тестовым Telegram; реальное подключение ожидает размещения сервиса.

## Собственный бот · после разрешения проблемы Defender

1. Установите Codex и войдите в свой аккаунт ChatGPT. Требуются Windows 10/11, .NET Framework 4.8 и установленный `codex.exe`.
2. Скачайте EXE из Releases и положите в постоянную папку.
3. Запустите его. **Окно не появляется: программа сразу работает в трее**, рядом с часами, иногда под стрелкой скрытых значков. Двойной щелчок открывает окно; правая кнопка мыши — меню.
4. Откройте **Telegram…** (в исходниках 1.2.0 затем **Настроить своего бота…**), введите токен своего бота и **свой** Telegram username. Отправьте боту `/start`, затем нажмите **Проверить и сохранить**. Бот определяется по токену; получатель проверяется как личный чат.
5. Если поиск не сработал, введите числовой ID своего личного чата. При известном ID username можно пропустить. Сохранённый ID используется повторно; при изменении получателя прежний ID не подставляется.
6. Нажмите **Проверить сейчас**. Если CLI не найден автоматически, укажите `codex.exe` кнопкой **Codex CLI…**.
7. Для одного теста нажмите правой кнопкой мыши на **Тест ×10** и выберите **Отправить 1 тестовое сообщение**. Обычный щелчок отправляет десять сообщений, не чаще одного в две секунды.

Telegram требует разрешения пользователя на личную переписку. Если входящие сообщения уже получает другой сервис или webhook, используйте известный личный ID: программа не меняет webhook и не подтверждает чужие входящие обновления. [Telegram Bot API](https://core.telegram.org/bots/api).

## Автозагрузка и трей

- **Папка автозагрузки** открывает стандартную папку Windows (`Win+R → shell:startup`). Положите туда EXE или ярлык на него. Администратор не нужен.
- Другой способ: нажмите **○ Автозапуск выключен**. Зелёная кнопка **✓ Автозапуск включён** подтверждает запись текущего EXE с параметром `--tray` в автозапуск пользователя.
- Чтобы убрать запуск через папку, удалите из неё EXE или ярлык. Перед удалением запущенного EXE выберите **Выйти** в меню трея. Запись, созданную кнопкой, выключите той же кнопкой. Если включили оба способа, отключите оба.
- Закрытие окна сохраняет работу в трее. **Выйти** полностью останавливает монитор.
- Повторный обычный запуск открывает окно уже работающей программы. `--show` показывает окно сразу; `--tray` сохраняет тихий запуск.
- После перемещения EXE обновите ярлык или заново включите автозапуск кнопкой. Работает один экземпляр на пользователя Windows.

## Уведомления

| Остаток основного лимита | Сообщения |
| --- | --- |
| 10% и ниже | 10 |
| 5% и ниже | 10 |
| 3% и ниже | 50 |
| 2% и ниже | непрерывно до восстановления или паузы |

Проверка Codex — каждые 60 секунд. Между сообщениями — минимум 2 секунды; `retry_after` Telegram соблюдается. Порог не повторяется на каждой проверке. При перескоке нескольких порогов выбирается самая срочная серия. Очередь сохраняется между запусками; при аварии в момент отправки возможен повтор одного сообщения.

**Пауза уведомлений** останавливает автоматические сообщения на 30 минут, но продолжает проверку лимитов. Зелёная кнопка с галочкой означает включённую паузу. Подсказки описывают текущий статус и следующее нажатие.

Устаревшие проценты не вызывают рассылку. После трёх неудачных проверок отправляется одно предупреждение о связи. Дополнительные лимиты вроде Spark показаны справочно. Покупку и применение сбросов программа не выполняет. Компьютер должен быть включён и иметь интернет; во сне монитор не работает. Звук зависит от настроек Telegram и телефона.

## Секреты и перенос

Релиз не содержит токенов, личных Chat ID, авторизации Codex или профиля автора. Новая установка имеет пустые настройки.

- `%LOCALAPPDATA%\CodexUsageSentinel\settings.json` — настройки; токен защищён Windows DPAPI для текущего пользователя.
- `%LOCALAPPDATA%\CodexUsageSentinel\alerts.json` — состояние уведомлений.
- Не переносите эти файлы на другой ПК и не загружайте на GitHub. На новом компьютере подключите общий бот через новую ссылку Start или заново введите токен собственного бота.
- `codex.exe` использует существующий локальный вход. Монитор не извлекает и не копирует секреты Codex.

## Сборка

**Через окно:** скачайте исходники (**Code → Download ZIP**), распакуйте и скачайте `Build.exe` из Releases. В Build.exe выберите папку проекта и нажмите **Собрать EXE**. Результат — `dist\CodexUsageSentinel.exe`. Build.exe нужен вместе с исходниками.

**Через PowerShell**, из папки проекта:

```powershell
powershell -NoProfile -ExecutionPolicy Bypass -File .\build.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\test.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File .\verify-release.ps1
```

Сборка создаёт `dist\CodexUsageSentinel.exe`, `dist\Build.exe` и `dist\SHA256SUMS.txt`. Используется штатный компилятор .NET Framework, без NuGet. Тесты не отправляют реальные сообщения. GitHub Actions также собирает и проверяет исходники.
