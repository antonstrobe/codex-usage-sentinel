# Быстрый запуск на другом компьютере

1. Установите **Codex для Windows**, войдите в свой ChatGPT-аккаунт.
2. [Скачайте ZIP проекта](https://github.com/antonstrobe/codex-usage-sentinel/archive/refs/heads/main.zip), распакуйте его в постоянную папку. Откройте эту папку как проект в Codex.
3. Вставьте сообщение:

> Прочитай AGENTS.md и docs/SETUP_WITH_CODEX.md. Проверь исходники, собери и проверь Codex Usage Sentinel, запусти его в трее без автозапуска. Найди мой локальный Codex и проверь чтение лимитов. Помоги настроить мой Telegram. Не копируй чужие настройки или секреты. Если Defender обнаружит угрозу, останови запуск и объясни результат проверки.

4. Откройте значок программы около часов → **Открыть**. В **Будильники…** задайте процент, число сообщений и интервал. **Тихий статус** включает одно сообщение с процентами, обновляемое каждую минуту без звука; после будильника оно переносится вниз. Закройте окно — программа останется в трее.
5. После перезагрузки в том же проекте напишите Codex: **«Запусти Codex Usage Sentinel в трее»**. Повторная установка не нужна. Для остановки: меню значка → **Выйти**.

Автозапуска, ярлыков и EXE на рабочем столе не требуется. Локальный файл остаётся в `dist/CodexUsageSentinel.exe`. Программа продолжает работать и после окончания диалога с Codex, пока её не закрыли или не завершили сеанс Windows. Компьютер должен быть включён и иметь интернет.

## Подключение Telegram

**Общий бот пока не готов к подключению: оператор ещё не установил сервис.** Одного Start сейчас недостаточно. Для этого режима дождитесь от оператора рабочего HTTPS-адреса и подтверждения, что ваш Telegram username разрешён.

После этого откройте **Telegram…**, укажите адрес, свой username и имя компьютера. Нажмите **Подключить через Start**, затем **Start / Запустить** именно по открывшейся ссылке. Она действует 10 минут. Дождитесь зелёного статуса подключения в программе. Токен общего бота и чужой Chat ID не нужны.

Если хотите настроить уведомления до готовности общего сервиса, нужен **ваш собственный бот**: **Telegram… → Настроить своего бота…**, токен из BotFather в защищённом поле программы, ваш username, Start в личном чате. Этот вариант отдельный; он не подключает общий бот. Токен в чат Codex не отправляйте.

Для проверки выберите **Лично мне** или **В группу** и нажмите **Тестовое сообщение**: одно сообщение уйдёт только в выбранный чат. Правая кнопка открывает серию из десяти. Проверьте звук уведомлений на телефоне.

Групповой режим требует прямого подключения бота по локально сохранённому токену. Добавьте этого бота в группу и выберите её через **В группу → Найти группы**; программа проверит доступ перед сохранением. Получать уведомления в группе можно без установки программы каждому участнику: монитор передаёт лимиты того компьютера, где запущен. Токен общего бота участникам для чтения сообщений не нужен. Для собственных лимитов другого компьютера потребуется отдельная установка и настройка доступа; не копируйте чужие токены.

## Если Defender предупреждает

У старой версии было обнаружение `Behavior:Win32/DefenseEvasion.A!ml`, причина не установлена. Запуск через Codex или новая сборка не гарантируют отсутствия предупреждения. При блокировке остановитесь, сохраните название обнаружения и сообщите оператору; не отключайте защиту и не добавляйте исключения. [Подробности](../README.md#defender).
