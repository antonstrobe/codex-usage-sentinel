# Установка на другом компьютере

**Сейчас подготовлены только исходники 1.2.0. Сервис общего бота не установлен, подключение через Start ещё не доступно.** В опубликованном EXE 1.1.0 этой функции нет. Оператору нужна [инструкция размещения сервиса](SHARED_BOT.md).

**Статус EXE:** Windows Defender обнаружил `Behavior:Win32/DefenseEvasion.A!ml` при работе версии 1.1.0 на компьютере автора. Причина не установлена. Версия 1.2.0 добавляет общий бот, но не является подтверждённым исправлением обнаружения. До завершения проверки установку не рекомендуем. Не отключайте Defender и не добавляйте исключения ради запуска.

## Общий бот через Start

После размещения сервиса и разрешения установки оператор добавляет ваш Telegram username в список доступа и передаёт HTTPS-адрес. Вам не нужен токен бота или числовой Chat ID.

1. Установите Codex на своём компьютере и войдите в **свой** ChatGPT-аккаунт.
2. Поместите подходящий `CodexUsageSentinel.exe` в постоянную папку. Не копируйте чужие настройки.
3. Запустите EXE. Он появится в трее около часов. Дважды нажмите значок.
4. Откройте **Telegram…**. Укажите **свой username**, имя компьютера и адрес сервиса от оператора.
5. Нажмите **Подключить через Start**. Откроется ссылка на общего бота. Нажмите **Start / Запустить** именно по этой ссылке: она действует 10 минут и привязана к вашему username.
6. Вернитесь в программу. Зелёный статус **✓ Подключение включено** подтверждает завершение. Бот ответит, какой компьютер подключён.
7. Нажмите **Проверить сейчас** и убедитесь, что получены свежие лимиты. **Тест ×10** отправляет десять сообщений с интервалом не менее двух секунд.
8. Включите **Автозапуск** — кнопка станет зелёной с надписью **✓ Автозапуск включён**. Либо откройте **Папка автозагрузки** и положите туда EXE или ярлык.

Обычный Start без ссылки показывает инструкцию. Компьютер связывает именно ссылка из программы — через [Telegram deep linking](https://core.telegram.org/bots/features#deep-linking).

## Что получает каждый человек

- Программа читает лимиты локального Codex на своём компьютере.
- У каждого компьютера отдельный доступ только к личному Telegram-чату подключившегося пользователя.
- В уведомлении видно имя компьютера. Чужие настройки и получатели не подставляются.
- Токен общего бота хранится на сервере. Авторизация Codex остаётся на компьютере; сервер получает данные привязки и текст уведомления.
- `/status` показывает количество ваших подключённых компьютеров. `/stop` отзывает доступ всех **ваших** компьютеров; для возобновления нужна новая ссылка Start. Уже начатая отправка ещё может завершиться.
- Закрытие окна скрывает его в трей. **Выйти** завершает программу. Во время сна или выключения компьютера монитор не работает.

## Если не подключается

- **Аккаунт не добавлен:** оператор должен разрешить ваш username.
- **Ссылка истекла или чужой аккаунт:** создайте новую в программе с вашим username.
- **Start нажат, программа ждёт:** откройте новую ссылку из программы. Проверьте интернет и доступность сервиса.
- **Codex не найден:** кнопкой **Codex CLI…** выберите установленный `codex.exe` и убедитесь, что выполнен вход.
- **Бот отключён:** снимите блокировку; после `/stop` подключитесь заново.
- **Defender показывает угрозу:** остановите установку. Успешные тесты и обычное сканирование не доказывают ложное срабатывание.

## Собственный бот

**Настроить своего бота…** открывает прежний режим: свой токен BotFather, свой username или личный Chat ID. Токен сохраняется через Windows DPAPI. Для общего бота этот режим не нужен.

## Задача для Codex на новом ПК

> Прочитай README и docs/SECOND_COMPUTER.md проекта Codex Usage Sentinel. Сначала проверь доступность сервиса и статус предупреждения Defender. Если выпуск допущен к установке, помоги найти мой локальный codex.exe и подключить общий бот через Start с моим username. Не копируй чужие settings.json, токены или авторизацию Codex. Не отключай антивирус. Реальные тестовые сообщения отправляй только по моей просьбе.
