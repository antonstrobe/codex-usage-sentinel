# Инструкция для Питера и других разрешённых участников

1. Откройте Telegram-бота, ссылку на которого дал владелец, и нажмите **Start / Запустить**. Если вы подключаетесь по заранее разрешённому имени, аккаунт должен состоять в настроенной общей группе.
2. Отправьте `/menu` в личном чате с ботом или нажмите **Управление** под сообщением с процентом в группе.
3. **Будильники** → выберите событие или добавьте новое. Задайте процент, количество сообщений и интервал; включите событие. Включённая кнопка зелёная и с галочкой.
4. **Тестовое сообщение** проверяет выбранного получателя: один тест или десять. **В группу / Лично владельцу** переключает общий адрес отправки; «лично» означает владельца монитора.
5. **Источник лимитов** показывает реальную квоту CLI WeChat. Astra Ultra — запрошенный режим; если CLI отдаёт только общий лимит Codex, это прямо указано. Это лимит серверного аккаунта, не автоматически вашего личного аккаунта.

**Скачивать проект, собирать EXE, держать компьютер включённым и просить Codex запускать монитор больше не нужно.** Он работает на сервере. Для тишины используйте паузу будильников или выключите нужное событие; тихие проценты включаются отдельно.

Если бот не показывает меню, владелец должен разрешить ваш Telegram ID или заранее согласованное имя. Токен бота участникам не передаётся.

[Подробная инструкция и установка серверного режима](SERVER_BOT.md). Для отдельно запрошенного локального мониторинга собственного аккаунта сохранён [Windows-клиент](SETUP_WITH_CODEX.md); его нельзя запускать параллельно с сервером для того же бота и чата.
