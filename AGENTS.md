# Codex Usage Sentinel

Windows WinForms / C# 5 / .NET Framework 4.8. Настройка: README.md и docs/SETUP_WITH_CODEX.md.

- Сохраняй один переносимый EXE для пользователя. Build.exe — отдельный инструмент для сборки из исходников.
- Запускай монитор в трее без окна; сохраняй открытие и полный выход из меню значка.
- Только читай лимиты Codex. Не применяй сбросы, не покупай кредиты и не запускай задачи модели для мониторинга.
- Не выводи и не добавляй в Git токены, ключи, cookie, файлы авторизации и личные настройки, даже зашифрованные. Telegram-токен вводится локально пользователем и хранится через DPAPI CurrentUser.
- Никаких встроенных личных ботов, username, Chat ID или путей конкретного ПК. Тестовые данные только фиктивные.
- Отправляй только в подтверждённый личный чат. Смена получателя не должна переиспользовать ID прежнего. Не отключай webhook и не подтверждай обновления другой интеграции.
- Между сообщениями минимум 2 секунды, учитывай retry_after. Реальные тестовые сообщения отправляй по просьбе пользователя.
- Интерфейсы в ночной теме. Включённые функции зелёные с галочкой и полным текущим статусом; выключенные нейтральные. Нужны подсказки и доступные имена; разовые действия отдельно от переключателей.
- Русский текст в UTF-8. Поддерживай штатный компилятор C# 5.
- Перед заменой EXE проверь точный PID и путь, сохрани резервную копию. Не останавливай другие сервисы.
- Выполни build.ps1, test.ps1, verify-release.ps1. После изменения окна осмотри реальный интерфейс; не выдавай непроверенный запуск на другом ПК за проверенный.
- Публикуй исходники по явному списку и проверенные release assets. dist и локальное состояние не коммить.
